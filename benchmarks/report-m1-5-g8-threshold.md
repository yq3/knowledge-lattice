# G-8 ② 指纹探针阈值校准（0.99/0.95 两档——可构造数据实测 + 受阻申报）

> 任务：M1-5 B-2（known-gaps G-8 收窄②：两档临时值用「网关正常版本抖动数据」
> 校准）。脚本：`benchmarks/calib_m1_5.py --exp threshold`；
> 数据：`data/bench-results/m1-5-calib-threshold.json`。
> **阈值数值落笔归 supervised-coding——本报告只陈述数据。**

## 可构造部分的实测（2026-10-26）

### ① 同模型控制组（确定性重嵌入）

TokenBagEmbedder 对 3 条哨兵（`adapters/embedder.SENTINELS`）重复嵌入：**min
cosine = 1.000000**——同模型重嵌入零抖动，两档阈值均不触发（无误报）。

### ② fp16 量化噪声底（halfvec 存储环回——真实良性变换）

42 段语料文本（corpus 前 400 字 × 39 + 3 哨兵）嵌入 2560 维 float32 →
float16 量化 → 回读 float32 → 与原向量余弦：**min = 1.000000（6 位小数）**、
P50 = 1.000000。即 fp16（halfvec 路径）量化对余弦的扰动 < 1e-6 量级——
**远低于 0.99 告警档**：良性存储/精度变换不会误触两档（无误报面）。

### ③ 漂移扫描（精确余弦构造——Gram-Schmidt，探针取 min 的保守面）

| 精确余弦 | 漂移幅度 | 两档判定（warn<0.99 / reject<0.95） |
|---|---|---|
| 0.9995 | 0.05% | ok（静默） |
| 0.999 | 0.1% | ok（静默） |
| 0.997 | 0.3% | ok（静默） |
| 0.995 | 0.5% | ok（静默） |
| 0.990 | 1.0% | ok（静默——边界） |
| 0.980 | 2.0% | **warn（告警审计）** |
| 0.960 | 4.0% | warn |
| 0.950 | 5.0% | warn（边界） |
| 0.930 | 7.0% | **reject（拒绝写入+关查询向量路）** |
| 0.900 | 10.0% | reject |

**判定几何**（P3-4 措辞修正：classify 为**严格小于**——边界值恰落在上一档不
触发，扫描表 0.990/0.950 两行即边界现象）：warn 档分辨率 = 漂移 **>1%**
（cos < 0.99 严格）；reject 档 = 漂移 **>5%**（cos < 0.95 严格）；漂移 ≤1% 的
换底模事件两档均不可见（静默区）——「网关正常版本微调」若引起 ≤1% 余弦偏移，
当前两档不设防（这是「太松漏报」面的量化：粒度即 1%/5% 两档）。

## 受阻申报（真实抖动分布）

「网关正常版本抖动数据」不可本地构造——正常版本演进的真实余弦分布需要生产
网关在版本更新前后的同文本嵌入对（本地无网关/ollama，与 B-3① 同源受阻，见
report-m1-5-g6-real-model-deferred.md）。**已有结论可先行**：良性量化变换
（fp16）噪声底 ~1e-6，与 0.99 告警档间有 4 个数量级余量——0.99/0.95 两档
不存在「正常精度变换误报」风险；剩余标定问题仅是「正常版本微调的漂移幅度
落在静默区（<1%）还是告警区」——待真实网关数据。

## 校准执行建议（供 supervised-coding / M2 参考）

1. 网关版本更新窗口前后各取 3 哨兵嵌入（probe 现成机制——`FingerprintProbe`）；
2. 若 min cosine ∈ [0.99, ~0.98]（1%~2% 漂移）：两档现状即设计意图（告警可见、
   不拒绝写入）——无需调值；
3. 若正常版本漂移 >2%（告警频繁误报）：warn 档下调（如 0.98）——数据到齐后定。
